Which model called past elections better

Each model was run on every past election in the eight metros, using only information available before that election, and compared with the real result. Two measures: how many wards it gave to the right party, and how many council seats it gave to the wrong party. The changes were judged on 2016 and 2021, a choice made before the runs. 2011 is shown too.

"Seats to the wrong party": the model's council (each party's average seats, rounded so they add up to the council size) set against the real council. Every seat in the wrong place is counted once. A difference of one or two seats in a single city can come from simulation noise alone.
